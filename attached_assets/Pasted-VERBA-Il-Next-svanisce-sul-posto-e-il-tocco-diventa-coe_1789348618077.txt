1 · src/pages/QuizScreen.tsx — il Next non scappa, svanisce
════════════════════════════════════════════════════════════
CAUSA: `advancing` diventa vero in modo sincrono, quindi il pulsante esce
subito; e l'uscita ha y:10, cioè scende mentre svanisce. Il risultato è che
sparisce prima di quanto l'occhio si aspetti.

TROVA:
              initial={{ opacity: 0, y: 10 }}
              animate={{ opacity: 1, y: 0 }}
              exit={{ opacity: 0, y: 10 }}
              transition={{ duration: 0.2, scale: TAP_SPRING }}

SOSTITUISCI CON:
              initial={{ opacity: 0, y: 10 }}
              animate={{ opacity: 1, y: 0 }}
              // esce SUL POSTO: se scendesse mentre svanisce sembrerebbe
              // scappare, e l'occhio lo perde prima del tempo
              exit={{ opacity: 0 }}
              transition={{ duration: 0.2, exit: { duration: 0.34 }, scale: TAP_SPRING }}

2 · SpringTap ovunque — il passaggio due, mai fatto

CONTESTO: src/components/SpringTap.tsx definisce cinque categorie con una
logica precisa — più grande è l'oggetto, meno deve muoversi, perché l'occhio
misura i pixel di spostamento del bordo e non la percentuale:
  button 0.94 · icon 0.88 · chip 0.93 · card 0.98 · row 0.985
Diciassette elementi usano ancora valori scritti a mano. Vanno collegati.

REGOLA DI CLASSIFICAZIONE — applicala per ogni occorrenza:
· bottone d'azione primario (usa primaryButtonStyle)      → tapScale()
· icona sola, senza testo, sotto i 44px                   → tapScale("icon")
· pillola/chip con poco testo e bordo tondo               → tapScale("chip")
· card, riquadro o opzione grande e cliccabile            → tapScale("card")
· riga di una lista                                       → tapScale("row")

Per OGNI file qui sotto: aggiungi l'import se manca
  import { tapScale, TAP_SPRING } from "@/components/SpringTap";
e sostituisci il valore scritto a mano con la categoria giusta, aggiungendo
  transition={TAP_SPRING}
se non c'è già un transition. Se un transition esiste già, NON sovrascriverlo:
aggiungi solo `scale: TAP_SPRING` al suo interno, come è stato fatto nel Next
flottante di QuizScreen.
